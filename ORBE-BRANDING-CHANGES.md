# Orbe Studio — personalização visual

Esta distribuição usa ORBE como base técnica, com identidade visual própria do Orbe Studio.

## Alterações nesta revisão
- Tema escuro padrão alterado para Orbe Aurora.
- Paleta do tema escuro redesenhada com superfícies azul-marinho e acentos ciano.
- Tema claro correspondente com acento azul-ciano.
- Ícone de marca do Orbe aplicado à barra de título e aos ícones Hicolor.
- Nome de exibição dos temas atualizado para Orbe Aurora.

## Limites
- Nomes internos de crates e APIs ainda incluem `ORBE` para evitar uma renomeação mecânica que poderia quebrar o workspace.
- Atribuições e licenças dos autores do ORBE foram preservadas.
- Esta alteração personaliza a aparência e a marca; não afirma que as ferramentas do antigo editor web do Orbe já foram portadas.
- A compilação e os testes Rust precisam ser executados num ambiente com Rust instalado.
